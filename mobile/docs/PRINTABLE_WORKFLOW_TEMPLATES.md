# Printable Workflow Templates

These two templates are designed to be copied into a notebook, printed from a Markdown viewer, or used as a short in-app reference while building an Offline Knowledge Graph. They keep the workflow local-first: the owner decides what to capture, how to explain relationships, and where to store recovery copies.

> Print or save a copy that fits your own context. These templates support personal organisation and evidence review; they are not a substitute for regulated records, formal approvals, or specialist advice.

## Research workflow template

Use this template when investigating a question across sources, observations, hypotheses, or competing interpretations.

| Stage | Prompt | Completion check |
|---|---|---|
| Frame | What is the question, and what would a useful answer change? | [ ] I created one **Research question** concept. |
| Capture | Which sources, claims, quotations, or observations are most relevant? | [ ] I added three to five concise concepts. |
| Connect | Does each important source support, challenge, explain, or exemplify the question? | [ ] I explained each key relationship in a note. |
| Assess | What is missing, weak, uncertain, or contradicted? | [ ] I reviewed evidence confidence and added an open question. |
| Explore | Which one-hop neighborhood needs closer inspection? | [ ] I used Focus mode and recorded a next action. |
| Protect | What would I need to continue after a device problem? | [ ] I created a local ZIP and recorded its intended destination. |

## Technical decision workflow template

Use this template for software architecture, service design, operational investigation, or any decision with dependencies and trade-offs.

| Stage | Prompt | Completion check |
|---|---|---|
| Bound | What system boundary, interface, decision, or incident are you examining? | [ ] I created one **Technical decision** concept. |
| Map | Which components, users, dependencies, constraints, and failure modes matter? | [ ] I added the smallest useful set of related concepts. |
| Explain | Why does each dependency or trade-off exist? | [ ] I wrote a relationship note for each material link. |
| Test | What evidence, observation, or experiment could weaken the current assumption? | [ ] I added a question or evidence concept. |
| Navigate | Which affected neighborhood should be inspected together? | [ ] I used Focus mode, zoom, and filters to review it. |
| Protect | How will this reasoning be recovered or compared later? | [ ] I created a local ZIP and kept a second trusted copy when appropriate. |

## Using the role-specific starters

The first-concept wizard now includes **Research question**, **Technical decision**, and **Creative seed** choices alongside the general reading, project, and open-question starters. Each pre-fills an editable title, note, and concept kind. Select one when it shortens the blank-page moment, then replace every word that does not fit your actual work.
