# KnowledgeGraph (Offline Adaptive Reasoning Engine)

**KnowledgeGraph** is a private, intelligent, offline-first personal reasoning system for Android.  
It uses:
- 🟦 Kotlin for orchestration and Android UI (Jetpack Compose + Material 3)
- 🟢 Clojure for adaptive graph logic and learning
- 🔵 Common Lisp for meta-reasoning and schema evolution
- 🟣 Mercury for provable inference and consistency

## Features
- Offline knowledge graph with dynamic relationships
- Semantic tagging and schema expansion
- DSL-based rule authoring
- Contradiction detection + correction
- Plugin-based adaptive learning
